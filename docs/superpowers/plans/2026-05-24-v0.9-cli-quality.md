## 9-1: `frank cache list/clear` 详细 plan

**用户故事**: 用户 `ls ~/.frank/cache/` 只看到 sha hash 不知道哪个是哪。要能列 url + size, 单清, 全清。

### File 1: `crates/frank-cli/src/cli/cache.rs` (NEW)

**职责**: `frank cache` 子命令实现

```rust
//! `frank cache <sub>` — cache 目录可视化 + 清理

use anyhow::Result;
use clap::{Parser, Subcommand};

use crate::installer::git;
use crate::state::State;

#[derive(Parser, Debug)]
pub struct Args {
    #[command(subcommand)]
    pub command: CacheCommand,
}

#[derive(Subcommand, Debug)]
pub enum CacheCommand {
    /// 列出 ~/.frank/cache/ 下所有 cached repo, 关联到 state.json 找出 url
    List,
    /// 清空 cache (危险: 不删 state.json, 下次 install 自动重 clone)
    Clear {
        /// 只清这个 skill 的 cache
        name: Option<String>,
        /// 跳过确认
        #[arg(long)]
        yes: bool,
    },
}

pub fn run(args: Args) -> Result<()> { ... }
```

**关键设计**:
- `list` 算法: read_dir `~/.frank/cache/` → 每个 dir 算 `url_cache_key(url) = dir_name` 反查 state.iter() 找匹配 url. 没匹配的 = orphan cache (state 已删但 cache 留着), 显示 `(orphan)`
- `clear` 算法: 无 name = 删整个 cache root + 提示 sha256 重算无影响; 有 name = state.get(name).source_path → cache_dir_for(url) → 删
- 输出格式: pretty table 跟 `frank list` 一致 (`| NAME | URL | SIZE | STATE |`)

### Tasks (bite-sized, 2-5 min each)

1. **写失败测试**: tests/cache_cli.rs 加 `cache_list_shows_url_for_managed`
2. **跑测试确认 fail** (cargo test cache_list_shows_url_for_managed)
3. **实现 minimal**: cache.rs 的 List 逻辑只够测试 pass
4. **跑测试确认 pass**
5. **commit**: `feat(cli): frank cache list`

9. **跑测试 pass**
10. **commit**: `feat(cli): frank cache clear`
11. **写失败测试**: `cache_clear_single_skill_keeps_others`
12. **实现 single clear**

### File 1: `crates/frank-cli/src/cli/install.rs` (modify)

**改动**:
- `Args` 加 `pub r#ref: Option<String>` (`--ref <branch>`)
- URL fragment 改成支持 `#branch:subpath` (双语义): 把 `#xxx` 看作 ref, `#xxx/yyy` 看作 ref + subpath
  - 实际更简单: 保留 `#subpath` 当 subpath, 加 `?ref=branch` query param 当 ref. 例: `--url https://.../foo.git?ref=master#path/to/skill`
